## قالب الملف

اسم الملف: `PR-<الرقم>-<UPPER-KEBAB>.md`.

1. **رأس:** الحالة وـ SHA الدمج، اللي كتبه، هل وصل السيرفر التجريبي والإنتاج، وأوّل نسخة تطبيق فيها، ورابط وثيقة الميزة.
2. **باختصار:** شن تغيّر للمستخدم، في سطرين أو ثلاثة.
3. **وين تلقاه:** المسار في التطبيق خطوة بخطوة، بنفس الكلمات اللي على الشاشة.
4. **مين يشوفه:** الصلاحيات، الجديد منها والقديم.
5. **كيف تستعمله:** الخطوات.
6. **قواعد لازم تعرفها:** شن يترفض، كيف يتراجع، وشن يتغيّر في الأرقام والخزينة.
7. **للنشر:** الـ migrations، الأوامر، الصلاحيات اللي تتعطى، الإعدادات، وهل يلزم تطبيق جديد.
8. **كيف تجرّبه:** قائمة تعلّم عليها.

لو تبدّل شي في ميزة بعد ما اندمجت، يتزاد قسم «تعديل لاحق» في ملفها، بالتاريخ، وفيه جدول قبل وبعد.
